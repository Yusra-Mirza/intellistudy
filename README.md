
# IntelliStudy 📚

An AI-powered learning assistant that helps students learn more effectively from their study materials.

## Features

- Upload PDF study materials
- Ask questions based on uploaded notes
- Generate quizzes from study materials
- Evaluate quiz answers and display scores
- Generate personalized study plans (planned)

## Tech Stack

- Python
- Streamlit
- Gemini API
- PDF text extraction
- Embeddings and semantic search (RAG)

## How It Works

1. Upload a PDF containing study material.
2. The application extracts relevant text.
3. Ask questions or generate a quiz from the material.
4. View AI-generated answers or quiz results.
